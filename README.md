# HydraJ

Proyecto para el curso de **Compiladores** — Universidad Nacional de San Agustín de Arequipa (UNSA).

## Descripción

HydraJ es un compilador/IDE experimental con tres modos de entrada:

- **Teclado** — editor de código tradicional con resaltado de sintaxis Java.
- **Mouse** — paleta de bloques visuales que inserta fragmentos de código.
- **Voz** — comandos de alto nivel reconocidos por audio.

La interfaz gráfica está construida con [ImGui Java](https://github.com/SpaiR/imgui-java) (LWJGL3).

## Requisitos

- JDK 17 o superior
- Gradle 8+

## Ejecución

```bash
./gradlew run
```
